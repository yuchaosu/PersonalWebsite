An interactive tool for learning quantum computing visually. Built with React and Three.js.

**[Launch Quantum Visualization &rarr;](/quantum-viz/)**

## Features

- **Bloch Sphere**: Visualize single-qubit states and watch how gates (H, X, Y, Z, S, T, Rx, Ry, Rz) rotate the state vector in 3D.
- **Circuit Builder**: Construct multi-qubit circuits with drag-and-drop, see tensor network visualizations and amplitude heatmaps.
- **Algorithm Walkthroughs**: Step through Deutsch-Jozsa, Bernstein-Vazirani, and other algorithms with educational narration.
